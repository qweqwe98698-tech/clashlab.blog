## 2. 评测维度深度拆解

### 维度一：线路架构与冗余备份

一个合格的高可用机场，绝不能依赖单一入口或单条光缆：
- **入口层**：必须具备全国多地 BGP 入口（如广港、沪日、京德），智能根据客户端所在运营商（电信、联通、移动）自动解析至最佳接入机房。
- **传输层**：核心链路必须配置双光缆热备（如深港专线 + 沪港专线互备）。当主海底光缆发生物理故障时，应能在秒级内无感倒换至备用线路。

### 维度二：晚高峰压力吞吐测试（20:00 ~ 23:00）

白天测速跑满 1000Mbps 没有参考价值，真正的试金石是**晚高峰拥堵窗口**：
- **丢包率（Packet Loss）**：必须 `<= 0.5%`。丢包一旦超过 3%，网页打开就会有明显顿挫感，在线会议会频繁卡顿。
- **延迟抖动（Jitter）**：必须 `<= 5ms`。抖动过大意味着底层队列排队严重，缓冲严重。

### 维度三：流媒体与高风控 AI 业务解锁矩阵

| 服务类别 | 代表平台 | 核心风控机制 | 优质机场解决方案 |
| :--- | :--- | :--- | :--- |
| **国际流媒体** | Netflix, Disney+, Max, Prime Video | 校验 IP 归属地库（MaxMind/IP2Location）与广播 ASN 属性 | 部署双栈原生落地 IP 或专用 SNI Proxy DNS 分流 |
| **高风控 AI 服务** | OpenAI (ChatGPT), Anthropic (Claude), Perplexity | Cloudflare Turnstile 挑战、IP Fraud Score 欺诈评分、无痕设备指纹 | 纯净原生住宅 IP (Residential IP) 或干净商业 IP 独立池 |
| **社交与游戏** | TikTok, Steam, PSN, Xbox Live | 区域定向审查、UDP 全锥形 NAT 穿透要求 | 支持 Full-Cone NAT 1 与纯原生解锁出口 |

```

                     │            常见机场消费陷阱警示              │
                     └──────────────────────────────────────────────┘
                                             │
      ┌──────────────────────┬───────────────┴──────────────┬──────────────────────┐
      ▼                      ▼                              ▼                      ▼
【陷阱 1：超长年付诱惑】  【陷阱 2：虚假节点倍率】      【陷阱 3：单点无冗余】  【陷阱 4：虚假全 IPLC】
 一次性预付 2~3 年       节点标注 0.1x 实扣 3x         全国仅一个入口机房      公网中转冒充专线
 极易半年内跑路关停      或者高峰期暗中限速            机房被通报全员失联      晚高峰丢包率破 20%
```

1. **绝对不要贪图便宜买 2~3 年的超长套餐**：行业动态变化极快，按月付或季付即使遭遇不可抗力也能将损失降到最低。
2. **警惕“全网千节点”噱头**：很多不良商家通过后端复用（单机多端口映射）制造出 200 个节点列表，实际背后只有 2 台廉价机器。
3. **查验工单与 Telegram 群组活跃度**：在购买前进入官方交流群，观察管理人员对故障的响应速度和群内真实用户反馈。
4. **测试退款承诺的兑现条件**：优质商家通常支持 24 小时或 3 天内按量无理由退款。
