## 1. 什么是机场？为什么你需要它？

「机场」是中文互联网对基于 Shadowsocks、VLESS、Trojan 等现代轻量级代理协议提供海量跨国节点中转服务的商业化平台的统称，相较于传统易被特征识别的 VPN，机场具有延迟低、速度快、支持精细分流与抗封锁能力强等核心优势。

对于刚接触跨境网络的小白用户来说，“机场”、“节点”、“订阅链接”、“专线”等术语往往让人眼花缭乱。

### 1.1 机场的概念起源
在网络技术中，早期的开源翻墙工具 **Shadowsocks** 使用了一只白色的“纸飞机”作为软件图标。后来，提供海量境外服务器节点中转服务的商业化平台，便被中文互联网形象地称为**「机场」**，而每个境外的代理服务器则被称为**「节点」**或**「停机坪」**。

```
+-------------------------------------------------------------------------------+
|                             机场核心运作原理                                   |
+-------------------------------------------------------------------------------+
|                                                                               |
| [你的电脑/手机]                                                               |
|        │ (通过分流规则自动判断目标网站)                                       |
|        ├──> 访问国内网站 (百度/微信/B站) ────> [国内骨干网] ──> 【直连毫秒响应】 |
|        │                                                                      |
|        └──> 访问海外网站 (Google/YouTube/AI)                                  |
|                 │                                                             |
|                 ▼ (本地加密封装)                                              |
|          [机场国内 BGP 入口机房]                                               |
|                 │                                                             |
|                 ▼ (通过企业内网 IPLC 专线或跨境隧道直达)                      |
|          [机场境外落地服务器 (香港/日本/美国)]                                 |
|                 │                                                             |
|                 ▼ (从境外本地网络高速访问)                                    |
|          [目标网站 Google / Netflix / OpenAI]                                  |
|                                                                               |
+-------------------------------------------------------------------------------+
```

### 1.2 机场与传统 VPN 的本质区别

| 对比维度 | 现代机场服务 (Clash / Sing-box 生态) | 传统企业级/商业 VPN (如 Express/Nord) |
| :--- | :--- | :--- |
| **底层协议** | VLESS Reality / Hysteria2 / TUIC / SS2022 | OpenVPN / WireGuard / IKEv2 / IPsec |
| **流量特征** | 具备高度 TLS 伪装，难以被防火墙特征识别 | 加密特征明显，在特殊时期极易被大面积阻断 |
| **分流能力** | **精细分流**：国内直连，国外走代理，无感共存 | 全局劫持，开 VPN 后国内微信、钉钉严重卡顿 |
| **传输链路** | 普遍采用国内 BGP 入口 + IPLC/IEPL 物理专线 | 跨国公网直连，晚高峰延迟高、丢包严重 |
| **流媒体/AI**| 针对 Netflix、Disney+、ChatGPT 部署专用住宅 IP | IP 集中在大机房，极易被识别并拒绝访问 |

### 维度一：根据用途匹配线路类型
1. **轻度学习与查阅资料**：Google、Wikipedia、GitHub，选择普通高性价比 BGP 中转机场（如 U1S1、飞猫云）即可。
2. **重度 4K 追剧与高清视频**：YouTube、Netflix 4K、Disney+，必须选择具备大带宽出口与流媒体解锁的专线机场（如光速云、光年梯）。
3. **AI 工具与跨境商务**：频繁使用 ChatGPT Plus、Claude 3.5 Sonnet、Midjourney 或从事外贸电商，必须选择拥有**纯净住宅 IP**的防风控专线（如灵猫网络）。

## 3. 防坑避雷四大铁律（新手必背）

新手防坑四大铁律是保障资金与使用体验的红线准则：坚决拒绝超长周期年付诱惑以防商家跑路、警惕虚标节点数量与假专线、仔细核实真实计费倍率，以及杜绝在不知名平台使用常用重要密码。

### 铁律 1：坚决月付，拒绝超长周期年付诱惑
- 不良商家最常用的套路是：“月付 20 元，年付仅需 60 元（相当于 5 元/月）”。
- **真相**：这种机场往往在超售收割一波年付资金后，在 3~6 个月内因线路成本无以为继而直接关停跑路。
- **准则**：坚持**按月付款**或**按季度付款**。只要用得不顺心，下个月直接换一家，损失最多十几元。

### 铁律 2：警惕虚假“全网 500+ 节点”噱头
- 很多劣质机场在后台使用一台几美元的廉价 VPS，通过绑定 50 个不同端口伪造成 50 个节点。
- **真相**：节点不在于多，而在于**真实质量与冗余**。拥有 15~30 个真 BGP 入口与真 IEPL 专线的机场，稳定性远超 500 个虚标公网节点。

### 铁律 3：看清节点计费倍率
- 节点列表后面的 `1.0x`、`0.5x`、`3.0x` 代表计费倍率。
- 如果你连接了一个 `3.0x` 的节点下载了 1GB 文件，机场后台会扣除 **3GB** 流量。购买前务必看清机场是否有大面积高倍率节点。

### 铁律 4：支付安全与个人隐私
- 国内微信、支付宝付款均通过正规三方聚合收银台完成，账单显示为日常消费，无需过度恐慌。
- 切勿在任何不知名机场的注册页面使用你的日常真实密码，建议使用随机独立密码注册。

## 4. 全平台客户端订阅导入图文教程

客户端订阅导入是将机场后台生成的专属订阅链接配置进 Clash Verge Rev、Shadowrocket 或 sing-box 客户端，从而实现一键同步全球节点、自动测速与智能规则分流的标准化操作流程。

购买机场套餐后，你会获得一条**「订阅链接 (Subscription URL)」**。以下是各平台主流客户端导入配置教程：

### 4.1 Windows / macOS 推荐：Clash Verge Rev

1. **下载安装客户端**：从 ClashLab 官方推荐渠道或 GitHub Releases 下载最新版 Clash Verge Rev。
2. **复制订阅链接**：登录机场官网后台「用户中心」，找到「一键导入」或「复制 Clash 订阅链接」。
3. **导入配置**：
   - 打开 Clash Verge Rev，点击左侧菜单栏 **「订阅 (Profiles)」**。
   - 在顶部输入框粘贴你的订阅链接，点击 **「导入 (Import)」**。
4. **开启代理**：
   - 切换到 **「代理 (Proxies)」** 页面，模式选择 **「规则 (Rule)」**。
   - 在策略组中点击测速，选择一个低延迟的绿色节点（如香港、日本）。
   - 在左侧 **「设置 (Settings)」** 中开启 **「系统代理 (System Proxy)」**，右下角图标亮起即可畅游全球网络！

```
+-------------------------------------------------------------+
|                     Clash Verge Rev 导入三步                |
+-------------------------------------------------------------+
| 1. [订阅管理] ──> 粘贴机场 URL ──> 点击「导入」             |
| 2. [代理选择] ──> 模式选择「规则 (Rule)」──> 选择可用节点    |
| 3. [系统设置] ──> 开启「系统代理」开关 ──> 完成联网          |
+-------------------------------------------------------------+
```

### 4.2 iPhone / iPad 推荐：Shadowrocket (小火箭)

1. **准备外区 Apple ID**：Shadowrocket 需在美区/港区 App Store 购买下载（售价约 $2.99）。
2. **一键导入**：在 Safari 浏览器中登录机场后台，点击 **「一键导入 Shadowrocket」**，系统会自动拉起小火箭并完成节点同步。
3. **手动添加**：如果无法一键导入，打开小火箭，点击右上角 `+` 号，类型选择 `Subscribe`，在 URL 处粘贴订阅链接并保存。
4. **开启连接**：全局路由选择 **「配置 (Config)」**，选择节点后打开顶部总开关，首次连接允许系统添加 VPN 配置即可。

### 4.3 Android (安卓) 推荐：Flclash / Sing-box / Clash for Android

1. 安装 Flclash 或 Sing-box 客户端。
2. 点击「配置」→「从 URL 添加」→ 粘贴订阅链接并更新。
3. 运行模式选择「规则分流」，点击启动按钮即可。

## 5. 新手高频避坑答疑（FAQ）

新手高频答疑汇集了延迟与体感关系、节点批量超时排查、规则模式与全局模式切换差异等最常见实操难题，帮助初学者快速排障并建立正确的跨境网络认知。

### Q1: 测速延迟显示 30ms 和 150ms 体验差距大吗？
- 对于网页浏览、看 4K 视频、发邮件，30ms 与 150ms 的体感差距微乎其微。
- 只有在玩外服即时对战竞技游戏（如 APEX、CS2、英雄联盟外服）时，低延迟才具有决定性意义。日常使用更应关注**丢包率是否为 0%** 而非极致的低 Ping 值。

### Q2: 为什么我的节点过几天就全部超时了？
- 可能是机场更新了后端服务器节点地址，而你的客户端尚未同步。在客户端中右键点击订阅，选择 **「更新订阅 (Update)」** 即可恢复。
