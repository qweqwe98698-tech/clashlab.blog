## 1. 为什么 Shadowrocket 依然是 iOS 代理首选？

**Shadowrocket（俗称“小火箭”）** 凭借其一次购买终身升级（$2.99）、超轻量级内存开销（常驻内存仅 20MB 左右）、丰富的功能（支持 VLESS、Hysteria2、TUIC、WireGuard、MitM 脚本、模块插件）以及极其省电的性能，始终是 iOS 平台普及率最高的代理工具。

```
+-------------------------------------------------------------------------------+
|                      Shadowrocket iOS 功能拓扑全景图                          |
+-------------------------------------------------------------------------------+
|  【入站层】  iOS Network Extension (NEPacketTunnelProvider) 虚拟网卡          |
|  ---------------------------------------------------------------------------  |
|  【解析层】  智能并发 DNS 解析 + Fake-IP 缓存 + DoH / DoT 加密传输             |
|  ---------------------------------------------------------------------------  |
|  【分流层】  智能规则集 (Domain / IP-CIDR / User-Agent / GeoIP) + 场景模式   |
|  ---------------------------------------------------------------------------  |
|  【扩展层】  HTTPS 解密 (MitM) + JavaScript 脚本 + 模块插件 (.module)          |
|  ---------------------------------------------------------------------------  |
|  【出站层】  Reality / Hysteria 2 / TUIC / Shadowsocks / Direct / Reject     |
+-------------------------------------------------------------------------------+
```

## 2. 正版购买与安全避坑指引

> [!WARNING]
> **绝对安全红线**：注册并登录非国区 Apple ID 时，**只能在「App Store」中登录**，**千万不要在 iPhone 的系统「设置 -> iCloud」中登录**！否则若公共账号被恶意锁定，会导致整台 iPhone 变砖。

### 推荐购买流程
1. **注册专属美区 Apple ID**：直接在苹果官网申请，地区选择美国（免税州如俄勒冈 Oregon 或特拉华 Delaware 可免消费税）。
2. **购买官方礼品卡**：通过 Apple 官网或支付宝（境外电商礼品卡频道）购买 $3~$5 礼品卡充值兑换。
3. **App Store 搜索下载**：认准开发者为 **Shadow Launch Technology Limited** 的官方原版应用，切勿下载仿冒的山寨图标软件。

## 3. 订阅导入与全协议支持

### 3.1 一键导入与更新设置

1. 打开 Shadowrocket，点击右上角 **「+」号**。
2. 在 **类型 (Type)** 中选择 **`Subscribe`（订阅）**。
3. 在 **URL** 栏粘贴机场提供的订阅链接，**备注 (Remark)** 填写机场名称。
4. 点击右上角 **完成 (Save)**，软件会自动拉取并解析所有节点。
5. **设置自动更新**：进入底部「设置」->「订阅」-> 开启「打开时更新」与「自动后台更新（间隔 24 小时）」。

```
[复制订阅链接] ──► [选择 Subscribe 类型] ──► [点击保存] ──► [自动生成延迟测试节点列表]
```

### 3.2 节点延迟测试与智能选择

- 点击首页任意节点下方的 **「连通性测试」** 或点击顶部 **「延迟测试」**。
- 支持 **ICMP Ping** 与 **TCP Ping**（建议在设置中选择 `TCP` 测试，以获取真实的 TCP 握手往返时延）。

## 4. 智能分流规则系统深度实操

默认的初始配置往往比较简陋。为了获得“国内应用秒开且不走代理、国外网站走对应节点、流媒体定向解锁”的最佳体验，推荐导入远程高级规则集。

### 4.1 导入权威远程规则配置

1. 点击底部菜单栏的 **「配置 (Config)」** 页面。
2. 点击右上角 **「+」号**，粘贴远程规则链接（如 ACL4SSR 或 Loyalsoldier 精简分流规则）：
   - `https://raw.githubusercontent.com/ACL4SSR/ACL4SSR/master/Clash/config/ACL4SSR_Online_Full_MultiMode.ini`
3. 下载成功后，点击该配置文件并选择 **「使用配置 (Use Config)」**。

### 4.2 全局路由四大模式精解

| 模式名称 | 运行机制 | 适用场景 |
| :--- | :--- | :--- |
| **配置 (Config)** | **【强烈推荐】** 严格按照规则分流，国内直连，国外走节点，广告拦截 | 日常绝大多数工作与生活主力模式 |
| **代理 (Proxy)** | 全局所有 App 的网络请求强制经过当前选中节点 | 规则未命中排错、临时测试单节点连通性 |
| **直连 (Direct)** | 所有流量完全绕过小火箭直接出网 | 相当于关闭代理功能 |
| **场景 (Scene)** | 根据当前连接的 WiFi 名称（SSID）或蜂窝网络自动切换不同节点与分流配置 | 办公室 WiFi / 家用 WiFi / 移动 5G 差异化策略 |

## 5. 进阶神技：MitM 解密与模块插件（Module）

Shadowrocket 支持强大的 **HTTPS 解密 (Man-in-the-Middle)** 与 **模块化插件系统**，可以实现 YouTube / Spotify 去广告、脚本自动签到与请求重写。

### 5.1 启用 HTTPS 解密 (MitM)

```
[1. 进入设置 -> 证书] ──► [2. 生成并安装 CA 证书] ──► [3. iOS 设置中信任根证书] ──► [4. 开启 HTTPS 解密开关]
```

1. 进入「配置」-> 点击当前配置文件右侧的 **「i」信息图标**。
2. 点击 **「HTTPS 解密」** -> 打开开关 -> 点击 **「生成新的 CA 证书」**。
3. 点击 **「安装证书」**，系统会提示下载描述文件。
4. 打开 iPhone **「设置」->「已下载描述文件」-> 点击安装**。
5. 打开 iPhone **「设置」->「通用」->「关于本机」->「证书信任设置」-> 勾选刚安装的 Shadowrocket CA 证书为「完全信任」**。

### 5.2 安装去广告与功能增强模块

1. 回到 Shadowrocket 底部 **「模块 (Module)」** 页面。
2. 点击右上角「+」号，添加常用模块链接（如 `BiliBili 去广告`、`YouTube 纯净模式`、`BoxJS 脚本中心`）。
3. 开启模块后，App 内的开屏与信息流广告将被直接重写过滤。

## 6. 自动化与续航调优最佳实践

1. **启用 On Demand（按需连接）**：在「设置」->「按需连接」中开启，当检测到网络连通时自动唤醒 VPN，断网时休眠，大幅节省后台电量。
2. **配合 iOS 快捷指令（Shortcuts）**：利用苹果「快捷指令」创建自动化任务，例如：`离开家时自动开启小火箭并切换为美国节点`，`连接到车载蓝牙时自动关闭小火箭`。
3. **关闭无用日志记录**：进入「设置」->「诊断」->「日志级别」设置为 `None` 或 `Error`，减轻闪存 I/O 写入负担与发热。
