# 2026 年度 50 家主流机场高可用 SLA 与稳定性普查

## 1. 调查背景与样本分布
为了给用户提供最真实的数据基准，ClashLab 实验室在过去 30 天内对市面上最具代表性的 50 家机场进行了全天候自动化探针采集：
- **监控探针分布**：覆盖上海电信、北京联通、广州移动三大国内骨干入口。
- **探测频率**：每 60 秒发起一次 ICMP 探测与 HTTP 204 连通性测试。

## 2. 核心指标统计

```
晚高峰 (20:00 - 23:00) 平均丢包率区间分布：
- [0% ~ 0.5%] (顶级专线级别) : 18% █▉
- [0.5% ~ 3%] (优质中转级别) : 24% ██▍
- [3% ~ 10%]  (轻度超售拥堵) : 16% █▋
- [> 10%]     (严重不可用)   : 42% ████████████▍
```

## 3. 评测室核心洞察
1. **多入口 BGP Anycast 是晚高峰稳定的底线**：采用单一入口机房的服务商一旦机房被通报或断纤，全员瘫痪率高达 100%。
2. **退款政策直接反映商家的服务底气**：支持 3 天内无理由按量退款的服务商，其平均 SLA 可用性高达 99.8%。
