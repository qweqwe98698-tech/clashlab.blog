# Android 平台 sing-box / Hiddify 快速配置

为安卓手机用户量身打造的新一代高性能代理上手指南。

## 1. 安装客户端
从 GitHub 或 Google Play 下载并安装 **Hiddify** 或 **sing-box for Android**。

## 2. 导入配置
1. 打开应用，点击主界面的「+」或「添加配置 (Add Profile)」。
2. 粘贴订阅链接，点击保存。
3. 应用会自动拉取节点并执行连通性测速。

## 3. 开启连接与后台保活
1. 点击中央的大按钮开启连接，在弹出的系统 VPN 权限申请中选择「确定」。
2. **防后台杀进程**：在系统「多任务界面」中长按 Hiddify 图标加锁，并在电池设置中选择「无限制 / 忽略电池优化」。
