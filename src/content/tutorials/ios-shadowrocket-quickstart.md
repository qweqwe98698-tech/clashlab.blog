# iOS 平台 Shadowrocket 极速配置指南

本教程指导你如何快速在 iPhone 上导入节点并开启无感智能分流。

## 1. 导入订阅链接
1. 打开 Shadowrocket，点击右上角 **「+」** 号。
2. 类型选择 **`Subscribe`**。
3. 在 URL 栏粘贴机场提供的订阅链接，备注填写机场名。
4. 点击右上角 **「完成」**，节点列表将自动下载呈现。

## 2. 选择全局路由模式
- 将首页下方的「全局路由」设置为 **「配置 (Config)」**。
- 这确保了访问国内微信、美团、淘宝走本地直连，访问海外服务走节点。

## 3. 启动连接
- 开启顶部的 **「未连接」** 开关，首次连接时系统会弹窗提示「Shadowrocket 想要添加 VPN 配置」，点击 **「允许」** 并验证 Face ID / Touch ID 即可！
