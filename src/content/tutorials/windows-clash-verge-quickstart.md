# Windows 平台 Clash Verge Rev 快速上手

本篇教程面向 Windows 10 / 11 用户，手把手带你在 5 分钟内完成从安装到出海冲浪的完整流程。

## 步骤一：下载与安装
1. 前往 ClashLab 工具库或 GitHub Releases 下载最新版 `.msi` 安装包。
2. 双击运行安装程序，按提示完成安装。

## 步骤二：导入订阅
1. 复制机场提供的 Clash 格式订阅链接。
2. 打开 Clash Verge Rev，点击左侧 **「订阅 (Profiles)」**。
3. 在顶部输入框粘贴链接，点击 **「下载 (Import)」**。
4. 单击激活刚刚下载的配置项（变为绿色即代表激活）。

## 步骤三：开启系统代理与智能分流
1. 点击左侧 **「代理 (Proxies)」**，在顶部选择 **「规则 (Rule)」** 模式。
2. 在节点列表中选择延迟较低的节点（如香港、日本）。
3. 回到 **「设置 (Settings)」**，打开 **「系统代理 (System Proxy)」** 开关。

现在打开浏览器访问 Google 或 YouTube，即可享受极速顺畅的全球互联网！
