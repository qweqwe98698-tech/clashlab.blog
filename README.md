# ClashLab (clashlab.blog)

> 专注网络协议演进、代理客户端生态与全球跨境网络基础设施的独立技术评测与深度内容平台。

---

## 🌟 核心特色

- **高端科技媒体排版**：采用黑白极简与深色科技风格，支持全端自适应。
- **16 家主流机场实测大盘**：包含 20:00–23:00 晚高峰实测数据、MTR 链路追踪、高清测速原图及多维动态筛选。
- **三层梯队与场景决策树**：T1 旗舰、T2 实用主力、T3 备用容灾清晰划分，针对 AI 生产力与 4K 流媒体提供专属决策流。
- **GEO 与 SEO 搜索引擎友好**：内置机器可读的 AI 核心结论速览（BLUF）、E-E-A-T 实验室评测方法论白皮书与 Schema.org 结构化数据。
- **全平台客户端教程库**：深度覆盖 Clash Verge Rev、sing-box、Shadowrocket、Hiddify 等客户端的内核调优与分流实战。

---

## 🛠️ 技术栈

- **框架**：[Astro 5.x](https://astro.build/) (Static Site Generation)
- **样式**：Vanilla CSS 模块化设计系统
- **图标与矢量图**：原生 SVG 高清矢量资产
- **SEO & 结构化数据**：`@astrojs/sitemap`, IndexNow 协议, Schema.org (TechArticle / Organization / FAQPage)

---

## 🚀 本地开发与构建

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器
npm run dev

# 3. 生产静态打包 (生成到 /dist)
npm run build

# 4. 本地预览生产构建
npm run preview
```
